# 6144 environments / 8000 iterations per skill

User-requested run: Isaac Lab DirectRLEnv + RSL-RL PPO, original BU10 legged CAD.

| Stage | Parallel environments | Additional PPO iterations | Initialization |
|---|---:|---:|---|
| Stand | 6144 | 8000 | Existing passed native standing weights |
| Sidestep | 6144 | 8000 | This run's confirmed standing weights |

Each iteration collects 24 control steps per environment: 147,456 transitions per iteration, 1,179,648,000 per stage, 2,359,296,000 total. Five PPO epochs and four minibatches update the same collected batch. The optimizer and iteration counter restart for each stage; policy architecture remains 23 actions / 110 observations.

Config: `config/stand_sidestep_6144_8000.json`. Both stages use a fixed learning rate of 0.0001 and entropy coefficient 0.0001; initial exploration standard deviation is 0.10 for standing and 0.15 for sidestep. Previously passed stages are deliberately trained again. One full attempt per stage is scheduled, with checkpoint snapshots every 100 iterations.

After each stage, select among this run's snapshots and confirm on 32 fresh-seed episodes (seed 50000). Historical snapshots are excluded from selection. Standing must pass confirmation before sidestep starts. Training counts do not guarantee evaluation success. Existing snapshots and policies are retained under `checkpoints/isaac/<skill>/runs/` before training; final policies and evaluations use `checkpoints/isaac/<skill>/`.

Launch and monitor from `~/projects/q1_leg_urdf`:

```bash
bash start_large_training.sh
systemctl --user status q1-leg-training --no-pager
tail -f outputs/native_curriculum.log
cat outputs/training_status.json
```

The live PhysX viewer is stopped during training to release GPU memory, then restored when the job exits if it was previously active. The HTTP viewer remains available for reference animation and saved replay. The background service survives terminal closure; computer suspension or reboot interrupts training.

```bash
systemctl --user stop q1-leg-training
```

This is native simulation training; real hardware has not been validated.
